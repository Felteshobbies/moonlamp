Earthshine

The averted half of the real moon is lit faintly by earthlight. 0 turns it off. On the lower brightness steps it is dropped automatically, because a glow weaker than one count would only show as scattered pixels.

Manual — switches to P5

0 % is new moon, 100 % is full. The four sliders set the colour directly; White alone is a plain white moon. Overall brightness comes from the steps above, so these only set the mix between the channels.

Ring

−1 LED+1 LEDFind pixel 0

Look at the lamp from the front and read the rim like a clock face: 12 at the top, 3 on the right, 6 at the bottom, 9 on the left. Set where the first LED of the strip sits, then whether the numbers run clockwise or counter-clockwise from it — follow the arrow printed on the strip.

Not sure which LED is the first one? Press “Find pixel 0”. One LED lights: the one this setting believes is at 6 o’clock. Nudge by ±1 LED until the lit one really is at the bottom — then the setting is right, and you never had to count a single LED. Press the program button on the device, or pick a program here, to leave that mode again.

Currently 270°. One LED is 9.0° on this ring.

Changing the count restarts the lamp: the output buffer is allocated once at start-up.

Output

Currently running: blocking. Temporal dithering shows several slightly different frames in quick succession; the eye averages them, which adds about three bits and makes single LEDs fade in smoothly at the low brightness steps. It needs the DMA path – if that is unavailable the lamp falls back automatically and says so here.
